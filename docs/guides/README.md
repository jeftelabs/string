# Guias práticos

## Objetivo

Os guias mostram como resolver tarefas comuns usando `@jeftelabs/string`, com passos e exemplos voltados ao uso do pacote. Eles complementam a [referência técnica](../references/README.md): use a referência para confirmar assinaturas e limites exatos.

## Escolha um guia

- [Começar a usar o pacote](./getting-started.md): instalar, importar, escolher o entry point e combinar os primeiros helpers.
- [Transformar nomes e palavras](./transformations.md): escolher formato de caixa, criar slugs, pluralizar e encadear operações.
- [Preparar e formatar texto](./text-processing.md): interpolar dados, escapar HTML, truncar, construir frases, quebrar e alinhar texto.

## Manutenção

Confirme cada exemplo no código e nos testes atuais. Quando uma API pública mudar, atualize o guia que a demonstra, a [referência da API](../references/api.md) e o README se a mudança afetar instalação ou uso inicial. Para validar exemplos, consulte o [guia de desenvolvimento](../development.md); não declare testes executados sem tê-los rodado.
